# Page requirements

One folder per page: `README.md` (requirements, acceptance criteria) and `preview.png` (design). Open only the page you are working on.

| Page | Folder | Summary |
|---|---|---|
| Overview | [00-get-started/overview](00-get-started/overview/README.md) | Application overview. |
| Forgot Password Page | [01-authorisation/forgot-password](01-authorisation/forgot-password/README.md) | Allows users to initiate the password recovery process by requesting a password reset email. |
| Reset Password Page | [01-authorisation/reset-password](01-authorisation/reset-password/README.md) | Allows users to create a new password after initiating the password recovery process. |
| Sign In Page | [01-authorisation/sign-in](01-authorisation/sign-in/README.md) | Allows existing users to authenticate and access the CV Builder application. |
| Sign Up Page | [01-authorisation/sign-up](01-authorisation/sign-up/README.md) | Allows new users to create an account and access the CV Builder application. |
| Verification Page | [01-authorisation/verification](01-authorisation/verification/README.md) | Allows users to verify their email address using a one-time verification code sent to their email. |
| Device Error Page | [02-errors-and-settings/device-error](02-errors-and-settings/device-error/README.md) | Displayed when the application is opened on devices with a screen width smaller than 768px. |
| No Internet Page | [02-errors-and-settings/no-internet](02-errors-and-settings/no-internet/README.md) | Displayed when the application cannot load content due to missing network connection or request failure. |
| Not Found Page | [02-errors-and-settings/not-found](02-errors-and-settings/not-found/README.md) | Displayed when a user navigates to a page that does not exist or is no longer available (404). |
| Settings Page | [02-errors-and-settings/settings](02-errors-and-settings/settings/README.md) | Allows users to manage application preferences and account credentials. |
| User CVs Page | [03-users/user-cvs](03-users/user-cvs/README.md) | Allows administrators to manage CVs created for a specific employee. |
| User Languages Page | [03-users/user-languages](03-users/user-languages/README.md) | Allows viewing and managing user languages. |
| User Profile Page | [03-users/user-profile](03-users/user-profile/README.md) | Allows viewing and managing user profile information. |
| User Skills Page | [03-users/user-skills](03-users/user-skills/README.md) | Allows viewing and managing user skills. |
| Users Page | [03-users/users](03-users/users/README.md) | Allows users to view employee information within the organization. |
| Skills Page (admin) | [04-skills/skills-admin](04-skills/skills-admin/README.md) | Allows administrators to manage the global skills catalog used throughout the application. |
| Skills Page | [04-skills/skills](04-skills/skills/README.md) | Allows users to manage their personal skill set by adding, editing, and removing skills with proficiency levels. |
| Languages Page (admin) | [05-languages/languages-admin](05-languages/languages-admin/README.md) | Allows administrators to manage the global list of languages available throughout the application. |
| Languages Page | [05-languages/languages](05-languages/languages/README.md) | Allows users to manage their personal language knowledge and proficiency levels. |
| CV Details Page | [06-cvs/cv-details](06-cvs/cv-details/README.md) | Allows users to view and update general CV information. |
| CV Preview Page | [06-cvs/cv-preview](06-cvs/cv-preview/README.md) | Allows users to preview the generated CV before exporting or sharing it. |
| CV Projects Page | [06-cvs/cv-projects](06-cvs/cv-projects/README.md) | Allows users to manage projects included in a specific CV. |
| CV Skills Page | [06-cvs/cv-skills](06-cvs/cv-skills/README.md) | Allows users to manage skills included in a specific CV. |
| CVs Page | [06-cvs/cvs](06-cvs/cvs/README.md) | Allows users to manage CVs. |
| Departments Page | [07-others/departments](07-others/departments/README.md) | Allows administrators to manage departments used within the application. |
| Positions Page | [07-others/positions](07-others/positions/README.md) | Allows administrators to manage positions used within the application. |
| Projects Page | [07-others/projects](07-others/projects/README.md) | Allows administrators to manage projects that can be assigned to employee CVs and used within the application. |
